# Codex 交接助手

**换一台电脑，接着上次的聊天。**

面向两台 **Windows x64** 电脑轮流使用的本地 Codex 聊天交接工具。提供中文图形界面、醒目的开始按钮、自动备份和文件校验；便携版双击运行，无需安装 Python。

[下载 Windows 便携版](https://github.com/regdiliKUN/codex-handoff/releases/download/v1.1.2/CodexHandoff-v1.1.2-windows-x64.zip) · [发布说明](https://github.com/regdiliKUN/codex-handoff/releases/tag/v1.1.2) · [详细使用说明](docs/使用说明.md)

> **v1.1.2 预发布版**：修复跨电脑接收后部分历史打不开的扩展路径问题，以及普通 ChatGPT 后台进程误拦截。37 项隔离测试通过；尚未完成第二台实体电脑上的原聊天续聊验收。这是第三方辅助工具，不是 OpenAI 官方同步功能。第一次请先备份，再做 A → B → A 往返验证。

## 三步开始

1. **选方向**：从这台电脑带走 / 接到这台电脑。
2. **选文件夹**：选择已有网盘同步目录、NAS 或移动硬盘里的中转文件夹。
3. **点大按钮**：开始导出聊天 / 开始接收聊天。

开始按钮固定在窗口底部；进度、失败原因和完成后的下一步直接显示在页面上。项目选项和日志默认折叠。

```mermaid
flowchart LR
    A[电脑 A：关闭 Codex 并导出] --> B[等待中转文件夹传输完成]
    B --> C[电脑 B：先备份再接收]
    C --> D[打开原聊天，继续工作]
```

## 可以做什么

- 携带聊天原文、归档、会话索引、支持版本的会话数据库及部分桌面项目元数据。
- 可选择随包携带普通项目文件夹、生成图片和可视化文件。
- 相同内容的文件复用已有对象，后续只新增变化文件及数据库快照；属于文件级增量。
- 接收前自动备份，可恢复最近一次操作前的记录。
- 检查运行中进程、SHA-256 校验、数据库完整性与结构、路径范围及本机交接基线。
- 保留聊天原文字节，适配活动元数据中的 Codex 数据目录和用户目录前缀。

## 第一次使用

1. 两台电脑安装相同版本的 Codex，并分别登录同一个账号。
2. 下载 ZIP 并解压，双击 `CodexHandoff.exe`。
3. 在 A 完全退出 Codex（包括托盘后台）和所有 Codex CLI，然后导出到中转文件夹。普通 ChatGPT 可以保留运行。
4. **等待所有文件同步或复制结束**，再到 B 退出 Codex并接收。
5. B 打开一条旧聊天，发送验证消息；然后 B 导出、A 接收，确认可以往返续聊。

接收会以快照替换交接范围内的聊天和项目文件，并删除其中快照没有的文件；本机原内容先进入备份，**不会自动合并两台各自的新聊天**。请先阅读[覆盖范围与恢复](docs/使用说明.md)。

## 适用范围

| 项目 | 当前支持情况 |
| --- | --- |
| 操作系统 | Windows x64；其他系统未验证 |
| 交接方式 | 两台电脑轮流使用，关闭应用后交接 |
| 数据库 | `state_5.sqlite`、`thread_history_1.sqlite`；不同结构会停止导入 |
| 项目目录 | 尽量保持相同盘符和路径；无自定义盘符映射 |
| Git worktree / 子模块 | 不支持自动迁移指针与注册关系 |
| 账号、config、插件、skills、MCP、claude-mem | 两台电脑分别配置，不随聊天迁移 |
| 传输通道 | 使用你已有的网盘、NAS、移动硬盘；程序不提供联网同步 |

迁移数据与备份包含聊天原文，未加密。两台电脑不要同时推进同一套记录；网盘未送达的更新无法被本机冲突检查提前发现。

## 从源码运行与测试

使用 Windows 上的 Python 3.12+（需包含 Tkinter），运行：

```powershell
py -3.12 handoff.py
py -3.12 -m unittest discover -s tests -p "test_*.py" -v
```

测试仅使用隔离的临时目录和模拟界面引擎，不操作你的真实聊天。37 项交接引擎、进程识别与界面测试均已通过；包含扩展路径和压缩记录的迁移回归，完整边界见[验证记录](docs/验证记录.md)。

## 构建便携版

```powershell
.\build.ps1
```

构建脚本在项目内创建 `.venv`，安装固定版本的 PyInstaller，将图形程序打包到 `dist/CodexHandoff.exe`。源代码运行不依赖第三方 Python 库。

## 数据位置

- Codex 数据目录：优先读取 `CODEX_HOME`，默认当前用户的 `.codex`。
- 工具设置、基线及备份：`%LOCALAPPDATA%\CodexHandoff`。
- 中转目录：由你在图形界面中选择；历史对象不会自动清理。

本仓库和发行包仅包含程序与说明，不包含任何用户聊天、登录信息或迁移快照。反馈问题时，请先移除聊天原文、凭据和私有路径。
