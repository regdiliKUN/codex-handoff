## 1.1.2 扩展路径修复与本机恢复 · 2026-10-19

- 根因：Windows 扩展路径 `\\?\C:\Users\...` 未命中普通用户目录前缀匹配。迁移包文件完整，但部分活动记录路径仍指向来源电脑。目标电脑独有聊天会按接收替换规则进入自动备份，不能仅凭旧侧边栏缓存判断记录已经丢失。
- 路径适配先统一 Windows 扩展盘符、扩展 UNC、普通路径的比较形式，仍按最长目录前缀匹配，保留目录边界约束，不改聊天正文。
- 37 项隔离测试通过：原有 35 项，以及扩展盘符/UNC/前缀边界适配、带扩展路径和 `.jsonl.zst` 文件的跨目录往返测试。
- 在一台目标 Windows 电脑上，先备份数据库、全局状态与索引，再定向修正无效路径，并从接收前自动备份补回本机独有记录及读取偏移。该次人工修复没有覆盖现有聊天行；本工具不提供自动合并功能。
- 修复后线程正文路径均可解析（包括 `.jsonl.zst` 压缩形式），两份数据库 quick_check 均为 ok。应用 read_thread 接口可读取恢复的聊天及原先保留来源电脑路径的聊天。
- PyInstaller 便携 EXE 已构建；运行时自检及隐藏窗口界面构造自检均正常退出，确认版本 1.1.2。
- 此验证确认应用接口读取和本机数据完整性，未自动发送续聊消息，也未完成第二台实体电脑上的往返验收。

## 1.1.1 进程识别修复 · 2026-10-19

- 原因：旧版仅按 `ChatGPT.exe` 进程名阻止操作，混淆普通 ChatGPT 与使用同名主程序的 Codex。
- 修复：使用 Windows 进程 API 读取可执行文件完整路径，区分 Codex 与普通 ChatGPT；保留 Codex、CLI 和执行器的离线保护。进程已退出则忽略，查询失败或来源不明则给出明确提示。
- 提示包含 PID、程序路径和 Codex 开机自启/后台驻留说明；开始前失败时自动展开操作详情。界面和使用说明不再要求关闭普通 ChatGPT。
- 35 项隔离回归测试通过（17 项交接引擎、12 项进程识别、6 项界面）。新增覆盖普通 ChatGPT 后台、Codex 同名进程、旧安装路径、大小写、混合进程、读取权限、进程消失和扫描失败。
- 本机真实只读检查：Windows API 可读取进程路径，并将 `OpenAI.Codex_26.1013.4894.0_x64__2p2nqsd0c76g0/app/ChatGPT.exe` 正确识别为 Codex；已退出的 PID 返回空。
- PyInstaller 便携 EXE 已重建；独立进程运行时自检及隐藏窗口界面构造自检均正常退出，报告版本为 1.1.1，Python 3.12.14 / SQLite 3.53.1。已替换原文件夹 EXE 并更新校验清单。
- 未执行真实聊天导入、导出或恢复，未修改启动项，未结束用户进程。重启后的实际操作尚需用户使用新版确认。
