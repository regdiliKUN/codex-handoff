- 本机真实只读检查：Windows API 可读取进程路径，并将 `OpenAI.Codex_26.1013.4894.0_x64__2p2nqsd0c76g0/app/ChatGPT.exe` 正确识别为 Codex；已退出的 PID 返回空。
- PyInstaller 便携 EXE 已重建；独立进程运行时自检及隐藏窗口界面构造自检均正常退出，报告版本为 1.1.1，Python 3.12.14 / SQLite 3.53.1。已替换原文件夹 EXE 并更新校验清单。
